# AI 업무이력 자산화 · 모델별 맞춤 프롬프트 4종

GitHub Pages용 정적 HTML 웹페이지. 저장소의 루트에 `index.html`, `.nojekyll` 등을 업로드하세요. 기존 `index.html`을 이 파일로 덮어쓰면 네 개의 AI 버튼에 맞춤형 프롬프트가 각각 연결됩니다.

- ChatGPT: 과거 수행 흐름·결정사항과 현재 작업상태 정리
- Claude: 장문 문서·수정 이유·검증 근거 정밀 대조
- Gemini: 텍스트·문서·이미지·표·코드 등 입력자료 통합
- Perplexity: 내부 이력과 외부 공개 기준의 출처 구분 및 확인

네 프롬프트는 동일한 공통 출력(A~E)을 유지합니다. 원본은 `prompts/`의 TXT에도 담았습니다.

## 사용 안내
버튼을 누르면 해당 AI의 프롬프트를 클립보드로 복사하고 외부 채팅 사이트가 열립니다. **새로 열리는 대화가 기존 작업 기록을 자동으로 가져오는 것은 아닙니다.** 원래 진행하던 대화에 프롬프트를 붙여넣거나 기존 작업 기록을 직접 첨부해야 합니다.

## 보안
HTML은 정적 파일이며 입력한 본문을 외부 서버에 전송하지 않습니다. 다만 복사한 프롬프트를 외부 AI 서비스에 입력하는 순간에는 해당 서비스의 정책이 적용됩니다. 개인·기관 비공개 데이터나 내부망 접속정보를 공개 채팅에 입력하지 마세요.

## 게시
Settings → Pages → Deploy from a branch → main/(root). 링크가 공개되면 네이버 QR의 연결 URL로 입력하세요.
